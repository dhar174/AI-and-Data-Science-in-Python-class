# PyQuest

Python puzzle adventure by Charles Niswander, originally built in Google AI Studio. This student-ready static edition corrects level 10 to Python try/except ValueError rather than JavaScript try/catch. Original vendor/library license headers remain in the bundle.

The correction preserves all other levels and mechanics. Four inventory branches, exception handling, syntax checks, an independent artifact review and an interactive level-10 completion test passed. The original Cloud Run version is retained as a recovery source, not the current student edition.

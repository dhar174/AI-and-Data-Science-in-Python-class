Session outline

What to do today

  1. Retrieval and goals: Recall the six elements of yesterday’s problem brief. | Predict the value of a variable after two assignments. | Explain the difference between data and an instruction.
  2. Worked example: Build and debug a function that loads prices, rejects nonnumeric input, and returns a mean.
  3. Guided practice: I Do/We Do/You Do notebook; trace table; debugging gallery; function-decomposition lab.
  4. Assessment: Python diagnostic and tested mini-script
  5. Homework: Complete two transfer problems and add the repaired error to the personal error log. (45 minutes)

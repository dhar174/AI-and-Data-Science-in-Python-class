Session outline

What to do today

  1. Retrieval and goals: Explain transfer learning. | State why subgroup errors matter. | Name one condition held fixed in an optimization experiment.
  2. Worked example: Translate a PyTorch image classifier definition and training step into Keras without changing task or evaluation.
  3. Guided practice: PyTorch/Keras API comparison; device check; profiling interpretation; deterministic-run discussion.
  4. Assessment: Framework translation and performance note
  5. Homework: Complete the framework note; continue the capstone in PyTorch unless an approved reason supports Keras. (40 minutes)

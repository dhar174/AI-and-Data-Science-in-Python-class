Session outline

What to do today

  1. Retrieval and goals: State the least-privilege rule. | Name one required agent stop condition. | Explain why base/SFT/DPO or route-specific baselines must use fixed cases.
  2. Worked example: Ask an assistant to summarize a CSV, then independently verify row counts, aggregations, missingness, cited records, and—where applicable—the base/SFT/DPO comparison table.
  3. Guided practice: Conversation-state test; CSV analysis verification; calculation cross-check; prompt/RAG/adapter/agent route comparison; base–SFT–DPO evidence review; rubric-based output evaluation.
  4. Assessment: Conversational data-analysis audit and capstone evaluation checkpoint
  5. Homework: Run the complete capstone evaluation set, including base/SFT/DPO evidence when applicable, and prioritize two failures. (70 minutes)

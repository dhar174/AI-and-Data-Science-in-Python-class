Session outline

What to do today

  1. Retrieval and goals: Explain next-token prediction. | State why fluency is not truth. | Name one context-related limitation.
  2. Worked example: Compare temperature-controlled responses to the same classification prompt and record model, parameters, latency, tokens, and cost.
  3. Guided practice: Environment validation; request anatomy; parameter experiment; cost estimate; secret-exposure repair.
  4. Assessment: API experiment log and credential-safety check
  5. Homework: Complete the redacted experiment log and verify that no secret appears in saved output. (40 minutes)

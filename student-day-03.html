Session outline

What to do today

  1. Retrieval and goals: Trace yesterday’s validation function. | Name one reason code that runs may still be wrong. | Predict the shape produced by selecting two columns from five rows.
  2. Worked example: Clean a small customer table containing a duplicate ID, missing age, currency text, and an impossible date.
  3. Guided practice: Array-shape investigation; DataFrame inspection; missing-value decision table; duplicate and type repair lab.
  4. Assessment: Data-wrangling notebook checkpoint
  5. Homework: Finish the validation section and write a five-sentence transformation rationale. (50 minutes)

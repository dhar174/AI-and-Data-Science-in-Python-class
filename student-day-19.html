Session outline

What to do today

  1. Retrieval and goals: Map one Keras component to PyTorch. | Explain what a GPU changes. | State one transfer-learning risk.
  2. Worked example: Forecast a univariate series using sliding windows and compare persistence, RNN, and LSTM results.
  3. Guided practice: Window construction; recurrent-state walkthrough; RNN/LSTM/GRU comparison; time-aware baseline evaluation.
  4. Assessment: Sequence-forecasting lab
  5. Homework: Complete the sequence evaluation and retrieve one classical-versus-neural evaluation connection. (55 minutes)

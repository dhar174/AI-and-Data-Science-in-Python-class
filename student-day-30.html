Session outline

What to do today

  1. Retrieval and goals: Explain a vector-similarity limitation. | Name the capstone retrieval test. | Distinguish metadata filtering from semantic similarity.
  2. Worked example: Build a read-only data lookup agent whose only tool accepts a validated customer ID and returns approved fields.
  3. Guided practice: Tool-schema design; trace inspection; permission-boundary exercise; agent loop lab; failure recovery.
  4. Assessment: Agent tool-contract prototype
  5. Homework: Complete the tool contract and run three safe-failure tests. (60 minutes)

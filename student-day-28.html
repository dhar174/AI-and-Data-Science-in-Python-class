Day 28 · Embeddings, RAG, agent memory, and retrieval evidence

5:30 p.m.–10:00 p.m. · Live online

Back to hub
Break: 7:55–8:25 p.m.The schedule below keeps this break protected.

Tonight's goal

Build an inspectable retrieval path and connect it to agent memory without confusing vector proximity, remembered content, or fluent generation with verified truth.

By the end, keep:
  • The retrieval record includes corpus/version, chunks, IDs, scores, metadata, query, answer, and source-support judgment.
  • The learner can identify whether a failure occurred in chunking, retrieval, context assembly, generation, or citation support.
  • The memory-backed agent either retrieves, reformulates, or abstains within a bounded retry budget.

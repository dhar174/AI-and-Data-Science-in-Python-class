Session outline

What to do today

  1. Retrieval and goals: Explain the base–SFT–DPO comparison and one limitation. | State one prompt or preference-data quality risk. | Explain why memory and model adaptation both require explicit boundaries.
  2. Worked example: Design a bounded support workflow, then compare prompting-only, RAG, PEFT/QLoRA, tool/agent, and justified hybrid routes against the project constraints.
  3. Guided practice: Chain decomposition; intermediate-output inspection; memory-type comparison; state-leakage scenario; prompt/RAG/PEFT/agent route matrix; dataset and evaluation planning; proposal clinic.
  4. Assessment: Chain trace, memory-risk review, capstone route decision, and adaptation feasibility record
  5. Homework: Submit the capstone proposal, route decision, evaluation set, fallback plan, and—if fine-tuning—model/dataset/adapter/quantization/training record. (50 minutes)

Break: 7:55–8:25 p.m.The schedule below keeps this break protected.

Tonight's goal

Design a bounded tool workflow that survives interruption while preserving thread identity, approval, retention, deletion, and memory boundaries.

By the end, keep:
  • The trace includes plan, validated tool call, observation, checkpoint, interruption, approval, resume, and safe failure.
  • The learner can show that a different thread cannot resume another thread's pending approval and that restart requires durable checkpoint storage.
  • The memory policy names who can write, read, correct, and delete each retained value.

Session outline

What to do today

  1. Retrieval and goals: Map one NumPy operation to PyTorch. | State the input shape for yesterday’s example. | Name one framework abstraction that still requires verification.
  2. Worked example: Repair a Dataset that returns strings, inconsistent shapes, and labels with the wrong dtype.
  3. Guided practice: Shape trace; computational-graph inspection; custom Dataset walkthrough; batch-debugging lab.
  4. Assessment: DataLoader and autograd debugging checkpoint
  5. Homework: Complete the debugging log and validate the first capstone batch. (50 minutes)
